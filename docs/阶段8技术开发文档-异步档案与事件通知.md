# 阶段 8：异步档案与事件通知

## 阶段目标

把项目导出从同步请求改为可恢复的持久任务，并将报价解析、协作者变化和导出结果统一接入通知中心。用户可以离开页面，任务完成后从通知返回档案工作台，在 24 小时有效期内完成鉴权下载。

## 已完成范围

- 新增持久化项目导出任务，支持排队、运行、成功、失败和过期状态。
- 服务启动时恢复排队或中断的任务，避免进程重启后任务静默丢失。
- 支持完整时间范围或指定日期范围，支持选择是否包含附件。
- ZIP 包含项目汇总 PDF、预算与付款记录 CSV、项目时间线 CSV、生成清单、证据附件和原始报价。
- 压缩包内文件名经过清理并处理重名；服务端对象键和文件名不写入完整项目地址。
- 下载必须处于登录态且拥有项目所有者权限，链接默认 24 小时失效。
- 失败和过期任务可重新排队，不重复创建业务数据。
- 报价解析成功/失败、导出成功/失败、协作者加入、权限变化和移除均写入事件型站内通知。
- 事件型通知查看后归入历史；风险型通知仍由条件协调器决定何时解除。
- 项目到期删除时同步删除导出任务、项目导出文件和原始上传目录。

## 数据结构

迁移 `b4e87f19c632_async_project_exports.py` 新增 `project_export_jobs`：

- 任务所属项目和发起用户；
- 状态、进度、当前阶段；
- 附件开关和可选日期范围；
- 私有对象键、文件体积和错误信息；
- 创建、开始、完成、更新时间与下载过期时间。

任务记录与导出文件分离。文件过期后删除私有文件并将任务标记为 `expired`，历史状态仍可用于重新生成和审计。

## 接口

- `POST /api/v1/projects/{project_id}/export-jobs`：创建导出任务，返回 `202`。
- `GET /api/v1/projects/{project_id}/export-jobs`：读取项目导出历史。
- `GET /api/v1/project-export-jobs/{job_id}`：读取单个任务进度。
- `POST /api/v1/project-export-jobs/{job_id}/retry`：重新排队失败或过期任务。
- `GET /api/v1/project-export-jobs/{job_id}/download`：在权限和有效期校验后下载 ZIP。

创建和重试要求近期登录。所有接口均从服务端任务反查项目权限，不接受客户端声明的文件路径或项目所有者身份。

## 任务执行与恢复

本地 Beta 使用独立 `ThreadPoolExecutor` 执行导出。API 只负责写入排队任务并快速返回；执行器分阶段提交进度，完成后记录对象键、大小、24 小时过期时间、审计事件和事件通知。

启动恢复会把遗留的 `queued`、`running` 任务统一重置为排队状态并重新提交。SQLite 环境使用通知唯一键和冲突忽略写入，避免前端轮询与后台完成同时触发重复消息。

## 事件通知语义

事件通知使用以下去重维度：

```text
用户 + 项目 + 事件代码 + 对象类型 + 对象 ID + 事件状态
```

本阶段事件代码包括：

- `QUOTE_PARSE_SUCCEEDED`、`QUOTE_PARSE_FAILED`；
- `EXPORT_SUCCEEDED`、`EXPORT_FAILED`；
- `MEMBER_JOINED`、`MEMBER_ROLE_CHANGED`、`MEMBER_REMOVED`。

通知行动路径回到报价预算页、项目页或指定导出任务。事件消息在用户查看后转为历史，避免长期占据活动风险计数；A1–A8 风险通知仍保持“已读不等于解除”的原有语义。

## 前端与交互

档案工作台按用户指定的 `gpt-taste` 规范实现。本阶段确定性结果采用 Editorial Split、Satoshi 字体、标题内联档案图形、横向手风琴、处理原则轮播、滚动固定任务说明和任务卡片堆叠。

页面遵循 AIDA：Hero 先解释可携带档案的价值；8+4、4+4+4 Bento 展示结构和安全边界；横向手风琴解释包内容；创建表单承担主行动；固定任务队列展示真实进度、有效期、下载和重试；末段以归档原则与创建行动收束。桌面和移动端均限制页面最大宽度，不产生横向滚动。

## 当前边界

- 当前 PDF 是项目摘要，明细以 CSV 和原始附件提供；包含验收问题表、附件图片缩略图和更复杂分页表格的正式报告排版仍需继续迭代。
- 本地线程池只适合单机 Beta。生产多实例应迁移到独立任务队列，并加入幂等租约、超时、重试次数和死信告警。
- 本地文件目录应替换为私有对象存储；下载可继续通过鉴权代理，或改为短时签名 URL。
- 过期文件当前在服务启动和下载访问时清理；生产环境还需独立周期清理任务。
- 大文件尚未分卷，超出对象存储或网关限制时需要拆分“数据报告包”和“附件包”。
